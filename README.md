# 놀자 유니버스 거래소 관리

Windows용 로컬 거래소 조회 프로그램입니다. 게임 계정에 로그인하거나 실제 거래를 실행하지 않습니다.

[최신 설치 파일 다운로드](https://github.com/danikim9003-byte/nolza-market-manager/releases/latest/download/nolza-market-manager-windows-x64.zip)

## 처음 실행
ZIP을 모두 압축 해제하고 **거래소 실행.cmd**를 누르세요. Node.js가 포함되어 별도 설치할 필요가 없습니다.
기존 거래소 서버가 실행 중이면 확인 후 종료하고 현재 폴더의 프로그램으로 시작합니다.
완전히 종료하려면 **거래소 종료.cmd**를 누르세요. 브라우저만 닫으면 자동 조회는 계속됩니다.

## 업데이트
실행 시와 실행 중 10분마다 GitHub 공개 배포의 최신 버전을 확인합니다.
알림 버튼 왼쪽의 업데이트 버튼은 새 버전이 있을 때만 활성화됩니다.
버튼을 누르면 다운로드와 SHA-256 검증, 압축 파일 검사를 거친 뒤 진행 중인 조회와 저장이 끝나기를 기다립니다.
프로그램 파일을 교체하고 재실행하며, 교체·시작 실패 시 이전 파일로 복구를 시도합니다.
GitHub 계정이나 Git 설치는 필요하지 않습니다.
GitHub 접속 실패 시 기존 기능은 유지되며 실패 표시와 수동 재확인을 제공합니다.
이번 업데이트 기능이 없는 이전 버전은 이 ZIP으로 한 번 교체해야 합니다.

## 개인 데이터
관심 목록, 목표 가격, 캐릭터, 판매 이력, 알림 설정은 프로그램의 **data** 폴더에 저장됩니다.
공유 ZIP과 업데이트에는 개인 데이터가 포함되지 않으며 업데이트는 data 폴더를 교체하지 않습니다.
프로그램을 다른 폴더로 새로 설치하면 기존 data 폴더도 함께 옮겨야 기록이 이어집니다.
MARKET_WATCH_DATA 환경 변수로 별도 저장 위치를 사용할 수 있습니다.

## 조회와 알림
관심 목록과 기존 판매 상태는 5분, 전체 판매중 탐색과 최근 판매 이력 보완은 10분 주기입니다.
이번 조회에서 등록 캐릭터 모두 판매중 10개가 확인되면 추가 판매중 탐색을 중단합니다.
최근 전체 판매 이력은 최대 20페이지(2,000건)이며 첫 조회는 기준으로만 저장합니다.
등록과 판매가 조회 사이에 일어나거나 조회 범위 밖으로 밀리면 누락될 수 있습니다.
취소는 숨기고 만료는 표시하며 수동 제거가 가능합니다.
판매 완료 추정은 등록에 초록색으로, 실제 SOLD 이력은 정산에 표시합니다. 공개 사이트 반영 시점에 따라 차이가 있습니다.
정산은 최근 100개를 유지하며 동일 매물 식별값과 건수로 중복 기록·알림을 방지합니다.

알림 켬/끔과 볼륨(기본 20%)은 data/preferences.json에 저장됩니다.
페이지를 보고 있지 않을 때 새 저가 정보·판매 정보에만 소리와 토스트를 표시합니다.
브라우저가 자동 소리 재생을 막으면 페이지를 한 번 클릭해 활성화하세요.
브라우저를 닫거나 탭 실행이 중지되면 소리와 팝업은 동작하지 않을 수 있습니다.

## 개발 및 배포
npm test와 npm run check로 검증합니다.
package.ps1은 개인 데이터가 없는 최초 설치 ZIP을 만듭니다.
publish-release.ps1은 버전을 올린 뒤 실행하는 개발자용 GitHub 배포 도구입니다.
